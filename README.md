# تطبيق شجرة عائلة خشبة بسمالوط

تطبيق أندرويد بسيط (Expo + WebView) يعرض شجرة النسب التفاعلية كاملة، بدون إنترنت.

## الخطوات

1. ارفع هذا المجلد كله إلى مستودع (repo) جديد على GitHub.
2. اذهب لتبويب **Actions** فى المستودع، شغّل الـ workflow يدويًا (Run workflow) أو ادفع (push) أى تعديل على فرع main — هيبني APK تلقائيًا.
3. بعد انتهاء البناء، حمّل الملف من قسم **Artifacts** باسم `khashaba-family-tree-debug-apk`.
4. ثبّت الـ APK على جهازك مباشرة (هذا debug APK للتجربة والاستخدام الشخصى فورًا).

## ملاحظات مهمة

- **الأيقونة**: عملت أيقونة placeholder بسيطة فى `assets/icon.png`. غيّرها بأى تصميم تحبه لاحقًا (نفس المقاس 1024×1024).
- **المحتوى**: كل شجرة النسب مدمجة داخل `treeHtml.js` كنص HTML كامل — لو عايز تعدّل أى اسم أو تضيف جيل جديد، عدّل فى هذا الملف مباشرة (ابحث عن الاسم بالعربى) وارفع (push) تاني.
- **النشر على Google Play**: هذا الـ workflow بيبني **debug APK** للتجربة فقط. لو قررت تنشره على المتجر زى تطبيق الأذكار، هتحتاج:
  - إنشاء keystore للتوقيع (signing key).
  - تعديل الـ workflow لعمل `assembleRelease` أو `bundleRelease` (لملف AAB) مع تمرير بيانات التوقيع كـ GitHub Secrets.
  - رفع الـ AAB على Play Console زى ما عملت مع `com.adhkar.morningevening`.
  - قل لى وأنا أظبطلك الـ workflow بالتوقيع لو حبيت تنشره فعليًا.
- **حزمة التطبيق (package name)**: حاليًا `com.nourapps.khashabafamilytree` — غيّرها فى `app.json` لو حابب اسم تاني.
